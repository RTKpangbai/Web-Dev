# Swan Pay

A responsive multi-page static website for **Swan Pay**, a fictional fintech platform offering Student and VIP payment cards with cashback, discounts, and secure transfers.

This project demonstrates modern CSS layout techniques (Flexbox and CSS Grid) to build a clean, mobile-friendly user interface for a card-based payment service.

## Features

- **Login / Sign-in page** — Clean flexbox-based authentication UI
- **Home page** — Hero banner highlighting Student & VIP cards plus key benefits (cashback, bank linking, fast transfer, security)
- **Product pages**
  - Student Card ($20) — Visa metal card with student discounts
  - VIP Card ($30) — Premium Visa metal card with enhanced cashback
- **Registration page** — Full sign-up form
- **Contact Us page** — Feedback form with card selection
- Fully responsive layouts using CSS Grid and Flexbox
- Consistent navigation and footer across pages

## Technologies Used

- **HTML5**
- **CSS3** (Flexbox, CSS Grid, custom properties)
- Google Fonts (Open Sans, Caveat, Poppins)
